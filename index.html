一、总体架构定位

1.1 目标架构

四池分离 + 两个自动阀门 + 市场自由交易 + 自由退出 + 协议资产三账分离。

  • 四池：云矿池、LP池、Treasury／平衡池、保障／保险池。
  • 两个自动阀门：
    1. 云矿池：控制 Token 生产／释放速度；
    2. Treasury／保障池：按跌幅等级自动保护协议资产、分级救市。
  • 市场原则：价格由 AMM 决定，不由管理员报价；用户自由买卖、自由退出。
  • 资产原则：现金、OS、矿机协议资产三账分离，禁止一笔钱重复计算两次。
  • 退出原则：3X 是账面目标，不是刚性兑付；实际可兑换 U 取决于 AMM 流动性和成交价格。

四、Treasury／平衡池：涨幅保护与卖币回流

4.1 涨幅保护

  • 每天当币价上涨超过 1%，Treasury 卖出 OS，使日涨幅尽量保持在 1% 以下。
  • 当卖币金额超过 1000U，系统自动进场购买矿机。
  • 购买矿机统一按：500U 现金 → 1000U 矿机协议资产。原文“700U 买矿机”口径不再采用。

4.2 卖币回流 1000U 的分配

卖币回流资金按 1000U 现金口径分配：

自动购买矿机500U 该 500U 的路径为进入 LP，形成 1000U 矿机协议资产；该矿机同样以 3 倍出局

记账口径：

  • 现金账：500U 用于购买矿机，100U 进分红池，400U 留平衡池储备；
  • 矿机协议资产账：因 500U 购买矿机，形成 +1000U 矿机协议资产；
  • “得到 1000U 矿机”是资产记账结果，不是额外 500U 现金，也不是可再次分配的现金；
  • 该 1000U 矿机协议资产同样以 3 倍出局为目标；
  • 禁止把 1000U 矿机资产再次当成 1000U 现金重新分配。
口径结论：原文不是“1000U 分配合计 1500U”的矛盾，而是“500U 进入 LP、得到 1000U 矿机”属于对 500U 购买矿机路径的资产记账说明。现金口径合计为 1000U。

4.3 回流资金不得按“新钱”重新分配

  • 这 1000U 已经是回流资金；
  • 不再按照“新钱 1000U”重新走一次 40/25/10/10/10/2/2/1 或 50/25/10/10/2/2/1；
  • 架构上禁止：一笔钱重复计算两次。

七、矿机资产与会计原则

7.1 矿机属于协议资产，不是现金

核心记账：

  • 500U 现金购买 1000U 矿机：
    • 现金：−500U；
    • 协议矿机资产：+1000U。
  • 绝不能把 1000U 矿机资产再次当成 1000U 现金重新分配。
  • 矿机未来产生的币，也必须单独进入：
    • 协议资产 → Token 生产／释放；
    • 不能再把 1000U 重复作为新资金重新分配。

7.2 三账分离

  1. 现金账；
  2. OS／Token 账；
  3. 矿机协议资产账。

8.2 领导级差奖表（V1-V9）

核心机制：以团队业绩（USDT）和区域要求为考核标准，实行 V1-V9 级差奖励。差奖采用差额补足制，计算单位统一为 USDT。

结算口径：按分区结算，每个分区按等级级差计算。

计算公式：
每个分区差奖 = 该分区组下静态收益 ×（当前等级比例 − 该分区最高下级等级比例）
上级总差奖 = 各分区差奖之和

防歧义规则：

  1. 以每条直推线形成的分区为单位，分别计算；
  2. 每个分区按等级级差计算：分区差奖 = 该分区组下静态收益 ×（当前等级比例 − 该分区最高下级等级比例）；
  3. 上级总差奖 = 各分区差奖之和；
  4. 同一笔静态收益只能计入一个分区并计算一次，不得跨区重复计算；
  5. 若某分区内没有达到等级的下级，则该分区最高下级等级比例按 0 计；
  6. 各级差奖合计不得超过最高等级比例对应的总拨比上限。

十、收益、封顶、复投与提现规则

10.1 LP 质押者

  • 静动态收益：3 倍封顶；
  • 原点位复投；
  • 权限收益：每天 0.3%～1%；
  • 收益得到的是平台稳定币，100% 可以转去游戏或消费；
  • 所有收益分为：
    • 最多可换 60% 币；
    • 40% 可用于游戏／消费：
      • 30% 游戏；
      • 10% 消费；
  • 提币：5% 进入重购池；
  • SWAP 卖出：3%：
    • 基金会 1%；
    • 共建者 1%；
    • 平衡者 1%。
【待确认7：LP 收益“100%可转游戏消费”与“60%换币+40%游戏消费”的关系】 需统一表述，明确先后关系：

  4. 可兑换边界、顺序、是否可逆、是否影响 3X 封顶需明确。

10.2 平衡 Treasury 参与者

  • 拿分红达到 3 倍封顶；
  • 复投自由；
  • 权限收益；
  • 所有 LP／平衡入金：
    • 10% 加权平均分红；
    • 以 1000 为 1 份；
    • 100 为 0.1 份；
    • 1000 以上才享有；
  • Swap 交易滑点 1% 加权；
  • 当 3 倍封顶没有复投，所有权限停止；
  • 收益分成：
    • 90% U；
    • 10% 消费；
  • U 提现手续费：10% 进入重购池。

  6. 封顶后权限停止的具体范围。

十一、重购池的定位

11.1 资金来源

  • LP 提币 5%；
  • 平衡 U 提现手续费 10%；
  • 防跌滑点中进入重购池的部分；
  • 其他指定资金。

11.2 用途

  • 跌时购买矿机产币留币；
  • 涨时卖出留 U；
  • 跌时有困难可扶持币价。

11.3 明确不做

  • 不拿去买币做销毁；
  • 销毁等于把大家的钱丢进大海，跌时没人能帮忙扶持币价。

十二、核心设计原则汇总

  1. 市场决定价格，不是协议决定。
  2. 用户决定退出，不是协议决定。
  3. AMM 决定成交，不是人工报价。
  4. 云矿池决定 Token 释放速度，不是人工每天修改。
  5. Treasury 只保护协议资产，不是控制用户。
  6. 用户达到自己的 3X 目标后自由退出。
  7. 协议不限制：卖多少、什么时候卖、卖几次、是否一次退出、是否继续持有。
  8. 实际获得多少 U，取决于当时 AMM 流动性和实际成交价格。
  9. 必须区分“3X 账面目标”和“实际市场可兑换金额”。
  10. 只有价格跌幅达到预设等级，Treasury／保险池才自动介入。
  11. 现金、OS、矿机资产三账分离。
  12. 禁止一笔钱重复计算两次。
